# odin-recipes
Recipe Website (HTML Only)
Project Overview
This project is a simple, multi-page website built entirely using raw, semantic HTML. The primary goal is to master the fundamentals of document structure, text formatting, and page linking before introducing any design elements.

As noted in the project blueprints (9340588390993837453.jpeg, 16370824225684658948.jpeg), the website will not look pretty initially. It relies completely on the browser's default styling (black text, standard fonts, and blue hyperlinks) to keep the core focus entirely on building solid HTML chops (9340588390993837453.jpeg, 16370824225684658948.jpeg). This project acts as the structural foundation, which will be revisited and styled in a future phase using CSS (9340588390993837453.jpeg, 16370824225684658948.jpeg).

Technical Skills Practiced
By building this project, you will demonstrate and reinforce the following foundational web development skills:

File Architecture & Directory Navigation: Setting up a clean project folder containing an index.html main page alongside separate recipe files (e.g., recipe1.html, recipe2.html) (9340588390993837453.jpeg, 16370824225684658948.jpeg).

Boilerplate Setup: Writing the core skeleton required for every web page, including <!DOCTYPE html>, <html>, <head>, <title>, and <body> tags (9340588390993837453.jpeg, 16370824225684658948.jpeg).

Semantic Content Hierarchy: Utilizing structural headings (<h1>, <h2>) to organize titles and sub-sections logically (9340588390993837453.jpeg, 16370824225684658948.jpeg).

Hyperlinking (The Core Web Concept): Implementing anchor tags (<a href="...">) to seamlessly link the main index page to the standalone recipe pages (9340588390993837453.jpeg, 16370824225684658948.jpeg).

Data Layout with Lists: Using unordered lists (<ul>) and list items (<li>) to neatly map out navigation links, recipe ingredients, and step-by-step cooking instructions (9340588390993837453.jpeg, 16370824225684658948.jpeg).

Website Structure
The architecture of the site is straightforward, focusing on clean paths and easy user navigation:

Plaintext
├── index.html          # The homepage containing the main title and links to all recipes
├── recipe1.html        # Recipe page 1 (Ingredients, steps, and descriptions)
├── recipe2.html        # Recipe page 2
└── recipe3.html        # Recipe page 3
Page Breakdown
Main Index Page (index.html): The introductory hub of the site featuring a main welcome heading and an bulleted list of hyperlinks guiding users to your various recipes (9340588390993837453.jpeg, 16370824225684658948.jpeg).

Individual Recipe Pages: Dedicated documents for each dish, using semantic paragraphs and lists to detail descriptions, ingredients, and preparation steps (9340588390993837453.jpeg, 16370824225684658948.jpeg).
