Recipe Website
Overview
This is a basic website built entirely with raw HTML. The purpose of this project is to practice core HTML structure and layout skills before adding any CSS styling. The current site uses standard browser styling and will be updated with colors and custom layouts in a later phase.

Skills Practiced
Project Structure: Organizing files, folders, and images on a local machine.

HTML Structure: Writing boilerplate tags like <!DOCTYPE html>, <head>, and <body>.

Content Hierarchy: Using <h1> and <h2> headings to organize titles and sections.

Lists: Creating ordered lists (<ol>) for recipe steps and unordered lists (<ul>) for ingredients.

Links & Images: Connecting pages together with anchor tags and embedding image files with correct relative paths.
