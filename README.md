Recipe Website
Overview
This is a basic website built entirely with raw HTML. The purpose of this project is to practice core HTML structure and layout skills before adding any CSS styling. The current site uses standard browser styling and will be updated with colors and custom layouts in a later phase.

Skills Practiced
Project Structure: Organizing files, folders, and images on a local machine.

HTML Structure: Writing boilerplate elements like DOCTYPE, head, and body.

Content Hierarchy: Using heading levels to organize titles and sections.

Lists: Creating ordered lists for recipe steps and unordered lists for ingredients.

Links and Images: Connecting pages together with anchor tags and embedding image files with correct relative paths.

Project Structure
index.html (The homepage containing links to all recipes)
